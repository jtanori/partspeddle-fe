# Catalog Rollout Plan (P1D)

**Goal**: Establish a prioritized taxonomy expansion strategy.

---

## 1. Rollout Tiers

### Tier 1: Pilot (Current)
*   **Categories**: Alternator, Engine, Door, Wheel.
*   **Focus**: Framework validation, Search Facet mapping, PDP Spec Rendering.

### Tier 2: High-Volume Marketplace (Q3)
*   **Categories**: Transmission, Starter, Radiator, Mirror, Headlight, Tail Light.
*   **Focus**: Volume scaling and Producer Matrix integration.

### Tier 3: Long-Tail Expansion (Q4)
*   **Categories**: ECU, Fuse Box, ABS Module, Transfer Case, Suspension, Interior/Seats.
*   **Focus**: AI Wizard training automation and automated VIN decoding integration.

---

## 2. Governance Lifecycle
1. **Definition**: New category spec requirements defined in `CATALOG_SPEC_DICTIONARY`.
2. **Certification**: Category validated via `GATE A.5` (Wizard form + Search facet + PDP grid).
3. **Deployment**: Promotion to production taxonomy.
