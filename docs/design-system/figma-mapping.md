# PPDS Figma Mapping

This document maps PPDS tokens and components to Figma.

## Tokens

| PPDS Token                  | Figma Variable            |
| --------------------------- | ------------------------- |
| `--color-brand-primary`     | `color/brand/primary`     |
| `--color-surface-primary`   | `color/surface/primary`   |
| `--color-surface-secondary` | `color/surface/secondary` |
| `--text-hero`               | `typography/hero`         |
| `--text-section`            | `typography/section`      |
| `--shadow-card`             | `elevation/card`          |
| `--shadow-floating`         | `elevation/floating`      |

## Components

| PPDS Component | Figma Component           |
| -------------- | ------------------------- |
| Button         | `Components/Button`       |
| Card           | `Components/Card`         |
| PartCard       | `Components/PartCard`     |
| SellerCard     | `Components/SellerCard`   |
| ImageGallery   | `Components/ImageGallery` |
| Sidebar        | `Workspace/Sidebar`       |
| PageHeader     | `Workspace/PageHeader`    |
| Toolbar        | `Workspace/Toolbar`       |
| InspectorPanel | `Workspace/Inspector`     |

## Maintenance

Keep Figma variables and components in sync with `src/index.css` and `src/components/ui`.
