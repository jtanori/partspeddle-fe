# PPDS Marketplace Specification

The public marketplace is the canonical consumer of PPDS foundations.

## Layout

- Centered content with max 1280px.
- Wide vertical spacing between sections.
- Hero sections with large imagery.
- Sticky action panels on part detail pages.

## Density

Comfortable.

## Key components

- `Container`, `Content`, `MainGrid`, `Section`, `Stack`
- `Card` / `CardSecondary` / `CardFloating`
- `PartCard`, `SellerCard`
- `ImageGallery`, `Price`, `Rating`, `VehicleLineage`
- `SearchInput`, `FilterGroup`, `Pagination`
- `Breadcrumb`, `Tabs`, `Accordion`

## Pages

- Home
- Search
- Part detail
- Seller detail
- Authentication
- Footer
