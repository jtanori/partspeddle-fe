# PPDS Content Guidelines

## Voice

Direct, helpful, industrial. No fluff.

## Labels

- Use sentence case for buttons and links.
- Use title case for page titles and section headers.
- Keep labels short; use tooltips for explanation.

## Empty states

Explain why something is empty and what to do next.

Example:

```text
No inventory yet
Add your first part listing to start selling.
[Add Listing]
```

## Error messages

State what happened, why it matters, and how to fix it.

Example:

```text
Could not save draft
Check your connection and try again. Your changes are stored locally.
[Retry]
```

## Microcopy

- "Add to cart" not "Add to Cart".
- "Save draft" not "Submit".
- "Publish" only when the listing is complete.
