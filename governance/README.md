# Governance — PartsPeddle / VinTrack

This directory contains the governance subsystems that guide planning, architecture, certification, and semantic change control.

## Subsystems

| Directory | Purpose |
| --------- | ------- |
| `planning/` | Roadmaps, phase implementation plans, session checkpoints, and archived plans. |
| `architecture/` | Architecture models, specifications, and design matrices. |
| `decisions/` | Architecture Decision Records (ADRs). |
| `certification/` | Production readiness and delivery certification evidence and generated reports. |
| `scgs/` | Semantic Change Governance System (SCGS) documentation and replay trace storage. |

## Entry points

- `GOVERNANCE.md` — glossary and interaction map.
- `PROJECT_MAP.md` — repository navigation.
- `governance/planning/platform-repository-evolution.md` — platform migration plan.
- `docs/PRC.md` — Production Readiness Certification checklist.
